# Yowie Bicycle Workshop static site

This is a simple static website ready for GitHub + Netlify.

## Files
- `index.html`
- `about.html`
- `services.html`
- `contact.html`
- `styles.css`
- `assets/`

## Deploy to Netlify
1. Create a new GitHub repo.
2. Upload all files in this folder.
3. Push to GitHub.
4. In Netlify, choose **Add new site** → **Import from Git**.
5. Select the repo.
6. Build settings:
   - Build command: leave blank
   - Publish directory: `.`
7. Deploy.
