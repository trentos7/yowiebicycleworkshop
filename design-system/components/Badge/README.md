# Badge

Small uppercase markers, all `letter-spacing` and never sentence case. Two real uses in the source:

- **Eyebrow** — sits directly above an `h1`/`h2`, `--accent` coloured, no background, `ds-eyebrow` type style. Always short (2–6 words): "What we do", "Why Yowie", "Northern Beaches Bicycle Workshop • E-Bikes & e-MTBs Welcome".
- **Pill badge** — a filled `--accent`/`--on-accent` pill overlapping a card's top edge, `ds-badge` type style. Used only for the "MOST POPULAR" pricing flag and the small uppercase service-type labels on the suspension-servicing cards ("FORK LOWER LEG SERVICE").

Don't invent a third badge treatment (e.g. an outlined badge) — every marker in the source is either bare eyebrow text or a solid accent pill.
