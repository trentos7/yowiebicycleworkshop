# Card

The base raised-panel pattern behind the hero card, feature panel, plain content card and the Google reviews panel. `--surface-card` fill, `--border` hairline, `--radius-lg`, `--shadow-card`. Padding varies by context (hero card `--space-3`, feature panel and reviews panel `--space-5`) — keep the fill, border, radius and shadow identical across every variant so panels always read as one family regardless of padding.

Provide whatever content the card needs (an image, a `ticks` list, an embedded widget) — the card itself carries no internal layout beyond padding.
